{       :L-Text [## ============================================================================================]}
{       :L-Text [## Two linked facts are shown together here:]}
{       :L-Text [##]}
{       :L-Text [## (1) CONTIGUOUS metaLines (no content line between them) are ONE metaBlock. The two meta-lines below]}
{       :L-Text [##     -- the file-level hide rule, then the :label1 line -- are a SINGLE block, and the block's depth is]}
{       :L-Text [##     that of its FIRST line. (Structurally this parses as one Meta block spanning both]}
{       :L-Text [##     lines, tagged depth1; the second line's "2" is recorded only at the line level and is subsumed.)]}
{       :L-Text [##]}
{       :L-Text [## (2) ORDER-OF-APPLICATION ACROSS BLOCKS: within that one block, hide{:label1} is issued BEFORE :label1]}
{       :L-Text [##     is applied, so the block's OWN attached content (line A) is NOT hidden. But the hide{:label1} rule]}
{       :L-Text [##     STANDS; a LATER block that comes to carry :label1 (by inheritance) IS hidden by it.]}
{       :L-Text [##]}
{       :L-Text [## EXPECTED RENDER — see OutFileFolder/:]}
{       :L-Text [##   - line A (attached to the contiguous block)  ->  SHOWN: hide{:label1} was evaluated before :label1,]}
{       :L-Text [##       so it did not fire on this block's own content.]}
{       :L-Text [##   - the second meta-line and line B            ->  HIDDEN: that block is a NEW block that inherits]}
{       :L-Text [##       :label1 from the block above, so the standing hide{:label1} now fires.]}
{       :L-Text [##]}
{       :L-Text [##   The instructive surprise: line A carries :label1 yet is SHOWN, while line B (no :label1 of its own)]}
{       :L-Text [##   is HIDDEN -- because :label1 reaches B by inheritance and the hide rule only "sees" it there.]}
{       :L-Text [##]}

{       :L-Text [##     * line A becomes HIDDEN: hide{:label1} and :label1 are no longer in one block, so the in-block order]}
